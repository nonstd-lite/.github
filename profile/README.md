## Post-C++98 library features via polyfills.

[![Repology](https://img.shields.io/badge/on-repology-blue.svg)](https://repology.org/projects/?search=nonstd-) [![Vcpkg nonstd-](https://img.shields.io/badge/on-vcpkg:nonstd–*-blue.svg)](https://vcpkg.io/en/packages?query=nonstd-) [![Vcpkg -lite](https://img.shields.io/badge/on-vcpkg:*–lite-blue.svg)](https://vcpkg.io/en/packages?query=-lite)

Please note that the various _lite_ projects are standalone projects, each a single-file header-only C++ library, without any dependencies other than the standard library.

Issues of collective interest to these projects are collected in [nonstd-lite](https://github.com/nonstd-lite/nonstd-lite).

These projects have been moved here from my [personal account](https://github.com/martinmoene).

**Projects:**

- [active-lite](https://github.com/nonstd-lite/active-lite) &ndash; Active objects for C++11 and later.
- [any-lite](https://github.com/nonstd-lite/any-lite) &ndash; A C++17-like any, a type-safe container for single values of any type for C++98, C++11 and later.
- [atomic-lite](https://github.com/nonstd-lite/atomic-lite) &ndash; A C++11 atomic operations library for C++98 and later (WIP).
- [bit-lite](https://github.com/nonstd-lite/bit-lite) &ndash; C++20 bit operations for C++98 and later.
- [boolean-lite](https://github.com/nonstd-lite/boolean-lite) &ndash; A strong boolean type for C++98 and later.
- [byte-lite](https://github.com/nonstd-lite/byte-lite) &ndash; A C++17-like byte type for C++98, C++11 and later.
- [expected-lite](https://github.com/nonstd-lite/expected-lite) &ndash; C++23 expected objects for C++11 and later.
- [indirect-value-lite](https://github.com/nonstd-lite/indirect-value-lite) &ndash; An indirect value-type for C++11 and later (p1950).
- [invoke-lite](https://github.com/nonstd-lite/invoke-lite) &ndash; C++17-like invoke() for C++98, C++11 and later (WIP).
- [jthread-lite](https://github.com/nonstd-lite/jthread-lite) &ndash; C++20's jthread for C++11 and later (WIP).
- [observer-ptr-lite](https://github.com/nonstd-lite/observer-ptr-lite) &ndash; An observer_ptr for C++98 and later (Extensions for Library Fundamentals, v2, v3).
- [optional-fun-lite](https://github.com/nonstd-lite/optional-fun-lite) &ndash; Functional algorithms for optional (lite) for C++98, C++11 and later.  
  See also [optional-lite](https://github.com/nonstd-lite/optional-lite).
- [optional-bare](https://github.com/nonstd-lite/optional-bare) &ndash; A simple version of a C++17-like optional for default-constructible, copyable types, for C++98 and later.
- [optional-lite](https://github.com/nonstd-lite/optional-lite) &ndash; A C++17-like optional, a nullable object for C++98, C++11 and later.
- [ring-span-lite](https://github.com/nonstd-lite/ring-span-lite) &ndash; A ring_span type for C++98, C++11 and later (p0059).
- [scope-lite](https://github.com/nonstd-lite/scope-lite) &ndash; C++ library extensions scope_exit, scope_fail, scope_success, unique_resource (C++ standard libraries extensions, version 3: Generic scope and RAII Wrapper.).
- [span-lite](https://github.com/nonstd-lite/span-lite) &ndash; A C++20-like span for C++98, C++11 and later.
- [status-value-lite](https://github.com/nonstd-lite/status-value-lite) &ndash; A class for status and optional value for C++11 and later, with C++98 variant also provided (p0262).
- [string-lite](https://github.com/nonstd-lite/string-lite) &ndash; String algorithms for C++11 and later.
- [string-non-lite](https://github.com/nonstd-lite/string-non-lite) &ndash; String facilities for C++98 and later.  
  Prefer to use [string-lite](https://github.com/nonstd-lite/string-lite).
- [string-view-lite](https://github.com/nonstd-lite/string-view-lite) &ndash; A C++17-like string_view for C++98, C++11 and later .
- [type-lite](https://github.com/nonstd-lite/type-lite) &ndash; Strong types for C++98, C++11 and later.
- [value-ptr-lite](https://github.com/nonstd-lite/value-ptr-lite) &ndash; A C++ smart-pointer with value semantics for C++98, C++11 and later.   
  See also [indirect-value-lite](https://github.com/nonstd-lite/indirect-value-lite).
- [variant-lite](https://github.com/nonstd-lite/variant-lite) &ndash; A C++17-like variant, a type-safe union for C++98, C++11 and later.
